### Malcolm Ferguson

Advanced Business student at UQ. I build small web tools, mostly browser extensions.

**[prompt-check](https://github.com/blueyferg/prompt-check)** — a Manifest V3 extension that reviews a prompt before you send it: scores the draft out of 100 and flags specific, fixable problems like unbounded scope, no stated output shape, or no rule for what the model should do when it doesn't know. Runs locally, no API key.

Published on [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/prompt-check-prompt-linter/) and [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/oifibcknfbimkbmkdlnlcogdcjekdlfj).

Most of what I build starts from a problem I've actually run into rather than from an interesting technology. I care more about whether a tool gets used than how clever it is under the hood.

Working mainly in JavaScript, the WebExtensions APIs, and static site tooling.
